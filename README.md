# Bangkok Drive 3D

Playable Three.js taxi simulator in a browser. Desktop WASD / arrows and touch controls. Drive in a procedural Bangkok-inspired city, choose a destination and earn fares.

```bash
npm install
npm run dev
```

**Scope:** This initial GitHub build is a 3D playable vertical slice, not yet real OSM streets or Roadarium-quality graphics. The extended local project ZIP includes a one-time OpenStreetMap extraction script. `npm run build` creates deployable static files.
